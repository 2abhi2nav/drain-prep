# Additional PoC Data

`Demographic_Profile_Chennai2011.csv` supplies ward-level population and age-group counts used by the
population-priority view.

`Sector_Wise_Power_National2024.csv` reports generating station capacity and generation for April 2023 to
January 2024. The PoC uses Tamil Nadu plant rows and generation share as an approximate population-served
proxy; it does not contain station-to-consumer mapping, Chennai distribution assets, or local outage events.
